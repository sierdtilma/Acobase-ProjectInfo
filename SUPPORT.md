# Support — Projectinfo (Acobase) Power BI visual

Dank je voor het gebruik van de **Projectinfo** custom visual van Acobase.

## Een probleem melden of een vraag stellen

Gebruik bij voorkeur de GitHub Issues van deze repository:

- **Nieuw issue aanmaken:** https://github.com/sierdtilma/AcoBase-Projectinfo/issues/new
- **Bestaande issues bekijken:** https://github.com/sierdtilma/AcoBase-Projectinfo/issues

Vermeld in je melding zo mogelijk:
- Versie van de visual (zie `pbiviz.json` → `visual.version`, of de eigenschap "Version" in Power BI).
- Power BI-omgeving: Desktop, Service, Mobile, of embedded.
- Stappen om het probleem te reproduceren.
- Screenshot(s) van het probleem, indien relevant.
- Eventuele foutmeldingen uit de browserconsole (F12 → Console) bij gebruik in Power BI Service.

## Contact

Voor vragen die niet via GitHub Issues afgehandeld kunnen worden, kun je contact opnemen via de contactgegevens in [`pbiviz.json`](pbiviz.json) (`author`).
